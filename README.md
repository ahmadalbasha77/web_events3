# دعوة زفاف رقمية — Ahmad & Layan

صفحة واحدة فاخرة، Mobile-first، تُفتح من رابط واتساب.

## التشغيل

افتح `index.html` عبر أي خادم ثابت (مطلوب للخريطة والخطوط):

```bash
python3 -m http.server 8080
```

ثم زر `http://localhost:8080`

للمعاينة المباشرة بدون المظروف: `http://localhost:8080/?open=1`

## التعديل

كل الأسماء والتواريخ والإحداثيات ورقم واتساب موجودة في كائن **`CONFIG`** أعلى `index.html`.
غيّر القيم هناك فقط، دون الحاجة للبحث في بقية الملف.

- `whatsapp.number`: بدون `+`، مثال `9639xxxxxxxx`.
